## Fixed scientific question and fresh identities

Estimate whole-network incorrect findings, missed links and depth/structure recovery for the unchanged shipped default elastic-net procedure under the original three continuous Gaussian generators at participant N80/N200. This is a narrow reference benchmark, not validation of arbitrary populations, other engines, interactions, causal direction or universal minimum sample size.

Take exactly repetitions **1 through 55**, inclusive, from each original scenario/N cell. Preserve every original case ID, index, generator seed and analysis seed. The original case manifest/seed audit supplies their predeclared identities; this is an intentional subset, not a new overlapping namespace. All six repetition-0 timing cases (indices0/80/160/240/320/400), including the quarantined development diagnostic at index0, are excluded from qualification. No output or fit is reused. The 330 selected identities have not been fitted in any completed, partial or diagnostic history checked before launch. Publish that inventory proof. Selection uses fixed ascending repetition and cost/precision, never observed accuracy.

The generators, columns Y/X1/X2/Z1/Z2, independent fully observed rows, and stipulated structures are exactly those in the [original scientific protocol](recursive_preview_validation_protocol.md):

- Noise: all independent standard normal; no links or non-root depths.
- Chain: X2=.6X1+.8E2; Y=.8X2+.6EY; retain X2->Y and X1->X2 at depths1/2.
- Correlated direct: X2=.4X1+sqrt(.84)E2; Y=.6X1+.6X2+sqrt(.672)EY; retain X1/X2->Y at depth1.

Both nuisance variables remain eligible until promoted. Every innovation is independent standard normal unless its dependence is specified. Never replace a failed identity, delete a condition, pool participant N or change a cutoff to obtain qualification.

Preserve B100, 80% subsampling, performance CV5x2, tuning CV3, retention .70, all original relevance/dependence thresholds, MSE, default grid/solver/max_depth3 and fold-local preprocessing. Only root Y and the original per-dataset seed override the default file. Preserve production layer finalization/recursion and the already checked four-process single-threaded checkpoint adapter. This protocol changes study size/execution, not the method. Bind fresh case contexts to the new immutable qualification manifest.

Independently replay saved generated rows, samples/splits, risks/contrasts, fitted-parameter reuse, finalized layers, links, group identities and depths. Use the existing structural scoring: a miss, extra link/group, nuisance promotion or wrong depth prevents exact recovery. Count datasets with any incorrect retained relation separately from missing expected links. Downstream links prevented by an upstream miss remain missing for whole-network recovery.

Keep unknown/error/timeout/missing identities in all55 planned rows; report inclusive best/worst-case bounds and withhold positive qualification if any case is unknown or fails integrity. A completed empty network is valid; an execution failure is not an empty network.

All planned cases in a stage must complete and pass integrity before positive qualification. Each noise cell requires incorrect-finding upper bound <=.10. The probability cutoffs are unchanged from the original protocol. Fewer replications reduce precision and change integer boundaries; this is not a participant-sample recommendation. Preserve all missed links/depth mistakes even when a cell qualifies.

If the true incorrect-finding rate were hypothetically1%in all six cells, the chance of passing all six incorrect-finding bounds would be about.514at n55 versus.751at n80. These are planning calculations, not observed error rates. Qualification may remain inconclusive despite useful performance. No loosening of the frozen guard follows a failure.
