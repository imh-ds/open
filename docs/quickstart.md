# OPEN quick tutorial

Start with **[OPEN, step by step](tutorial.html)** ([Markdown version](tutorial.md)) for a sequential Python
walkthrough. It introduces each function and argument when you need it, walks
through discovery, confirmation and fit separately, then progresses to recursive
well-being and anxiety networks with separate and combined figures. Controls,
engine choices and other settings follow as additional lessons. The
[runnable companion](../examples/tutorial/step_by_step.py) follows the core
walkthrough in order.

The HTML field guide provides plain-language workflow
choices, fold and sample-size guidance tied to the checked-in validation
evidence, runnable examples for one and two outcomes, embedded separate and combined network figures,
and interpretation notes:

**[Open the interactive OPEN field guide](index.html)**

The reproducible synthetic datasets and their generator are in
[`examples/tutorial/`](../examples/tutorial/). The [API guide](api.md) and
[method guide](method.md) provide reference detail.
