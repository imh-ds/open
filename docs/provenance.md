# Provenance

This repository was started on 2026-10-19 with a fresh history. It contains the
final method, the four supporting studies and how to reproduce them.

Development happened in [imh-ds/open-archive](https://github.com/imh-ds/open-archive),
which was named `imh-ds/open` until 2026-10-19. As a result:

- **Commit SHAs** in results files and interpretations (for example `198929b`
  and `572b5af`) refer to commits in `open-archive`. Long hashes labelled
  "source" or "manifest" are file hashes, which still match the files here.
- **Links** of the form `github.com/imh-ds/open/actions/runs/<id>` refer to
  Actions runs of the archived repository. Run IDs are unchanged in the archive.
- **Prereleases** referenced by the studies were copied into this repository
  under the same tag names. The originals remain in the archive.
- **Earlier designs and studies** stay in the archive: the subsample/consensus
  pipeline, random-forest and gradient-boosting engines, and earlier pilots and
  qualification studies. They are not part of the published method.

A full git bundle of the development history (all branches) is kept with the
archive.
